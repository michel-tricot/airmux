airmux is a self-hosted LLM gateway. Applications send requests to one endpoint using a supported SDK or the native
canonical API. airmux authenticates the workspace, applies policy, selects a model and provider credential, translates
the request, and records usage.

## What airmux provides

- One inference origin for multiple upstream provider families
- Compatible Chat Completions, Responses, and Messages surfaces
- A canonical request and response format for provider-neutral applications
- Workspace-scoped inference keys and permission-limited management keys
- Platform, organization, and workspace provider credentials
- Model, provider, price, parameter, request, denial, and fallback policies
- Buffered and streaming translation with tool calls, structured output, reasoning, images, and PDF inputs when the selected model supports them
- Usage, cost, latency, status, credential scope, and audit records
- Cached versioned configuration so separately deployed gateways keep serving during a control-plane outage
