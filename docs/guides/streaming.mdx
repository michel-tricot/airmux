---
title: "Stream responses"
description: "Consume incremental text, reasoning, tool calls, usage, and terminal events from airmux."
---

Set `stream: true` on any inference surface. airmux translates the provider stream into the caller's dialect while
preserving incremental text, reasoning, and tool-call arguments.

## SDK streaming

```python
import os

from openai import OpenAI

client = OpenAI(
    base_url=f"{os.environ['AIRMUX_URL'].rstrip('/')}/inf/v1",
    api_key=os.environ["AIRMUX_INFERENCE_KEY"],
)

stream = client.chat.completions.create(
    model=os.environ["AIRMUX_MODEL"],
    messages=[{"role": "user", "content": "Count from one to five."}],
    stream=True,
)

for chunk in stream:
    if chunk.choices and chunk.choices[0].delta.content:
        print(chunk.choices[0].delta.content, end="", flush=True)
```

## Raw Chat Completions stream

```bash
curl --no-buffer http://localhost:8080/inf/v1/chat/completions \
  -H "Authorization: Bearer $AIRMUX_INFERENCE_KEY" \
  -H 'Content-Type: application/json' \
  -d '{"model":"openai/gpt-4o-mini","messages":[{"role":"user","content":"Count from one to five"}],"stream":true}'
```

Chat Completions streaming emits:

1. One or more `chat.completion.chunk` events with `choices[].delta`
2. A terminal choice with `finish_reason` and a usage-only chunk with `gateway`
3. `data: [DONE]`

```json
{"id":"019...","object":"chat.completion.chunk","choices":[{"delta":{"content":"One"},"finish_reason":null}]}
```

```json
{
  "id": "019...",
  "object": "chat.completion.chunk",
  "choices": [],
  "usage": {"prompt_tokens": 12, "completion_tokens": 8, "total_tokens": 20},
  "gateway": {"finish_reason": "stop", "adjustments": []}
}
```

## Cancellation and failures

When a client disconnects, airmux closes the upstream connection and records the partial attempt with
`status=cancelled`. If the provider fails after streaming has started, the HTTP status is already committed, so the
stream carries a dialect-shaped error event instead.

The final usage can be estimated when a provider does not report complete token counts. Each fallback attempt produces its own usage event.

Run `uv run python examples/chat_stream.py` for parsed output or `uv run python examples/chat_stream_raw.py` to inspect every SSE line.
