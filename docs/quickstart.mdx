---
title: "Quickstart"
description: "Run airmux with Docker Compose and send a real request."
---

You need Docker with Compose 2.24.4 or newer and an API key for a provider in the
[shipped catalog](/docs/reference/models-and-providers).

<Info>
  Quickstart sends a real request that your provider bills.
</Info>

<Steps>
  <Step title="Download the release's Compose file">
    From an empty directory, download the latest [published release's](https://github.com/michel-tricot/airmux/releases)
    Compose file. It is pinned to the image verified for that release:

    ```bash
    curl -fsSLO https://github.com/michel-tricot/airmux/releases/latest/download/docker-compose.yml
    ```

    For a public deployment, set a private `POSTGRES_PASSWORD` in `.env` before the first start. If port 8080 is
    occupied, set `AIRMUX_PORT` and `AIRMUX_PUBLIC_URL` there too. See [Docker Compose](/docs/deployment/docker).
  </Step>

  <Step title="Start and claim the instance">
    ```bash
    docker compose up -d --wait
    docker compose exec airmux airmux quickstart --url http://localhost:8080
    ```

    Compose starts Postgres, migrates the database, and loads the model catalog before starting airmux. Quickstart asks
    for an owner account and provider keys. Enter one provider key and press Enter to skip providers you do not use.
    It creates an organization, a `default` workspace, and an inference key, then verifies it with a real request.

    Copy the inference key when it appears. It is shown once. The command always connects to port 8080 inside the
    container. If you changed the host port, replace port 8080 in its printed example request with your host port.
  </Step>

  <Step title="See the request">
    Open [localhost:8080](http://localhost:8080), or your configured public URL, and sign in. **Overview** shows usage
    and estimated cost. **Requests** shows the individual request after the event arrives, normally within seconds.

    Your application can use the inference key at `http://localhost:8080/inf/v1`. See [Use an SDK](/docs/guides/sdks).
  </Step>
</Steps>
