---
title: "Quickstart"
description: "Run airmux with Docker Compose and send a real request."
---

You need Docker with Compose 2.24.4 or newer and an API key for a provider in the [shipped catalog](/docs/reference/models-and-providers).

<Steps>
  <Step title="Download the release's Compose file">
    From an empty directory, download the latest release's Compose file:

    ```bash
    curl -fsSLO https://github.com/michel-tricot/airmux/releases/latest/download/docker-compose.yml
    mkdir -p airmux-config
    ```
  </Step>
  <Step title="Start and claim the instance">
    ```bash
    docker compose up -d --wait
    ```

    Choose the web app or CLI to set up the instance.

    **Web app:** Open [localhost:8080](http://localhost:8080) and choose **Create account**. Follow the setup steps to add provider keys and name your first organization. **Finish setup** opens that organization. Create a workspace, then open **Playground** and send a request. To connect an application, create an inference key in the workspace and copy it when shown.

    **CLI:** Run:

    ```bash
    docker compose exec cli airmux quickstart --url http://localhost:8080
    ```

    `quickstart` asks for an owner account, your first organization name, and provider keys. Press Enter at the organization prompt to use your email domain (for example, `acme.com`), or pass `--org "Your organization"` to set it ahead of time. Enter one provider key and press Enter to skip providers you do not use. It sets up your workspace, prints an inference key, and sends a real request.

    Copy the inference key when it appears. It is shown once.

    <Note>
      Requests from `quickstart` or the web app's Playground are billed by your provider.
    </Note>
  </Step>
  <Step title="See the request">
    Open [localhost:8080](http://localhost:8080), and sign in. **Overview** shows usage and estimated cost. **Requests** shows the individual request after the event arrives, normally within seconds.

    Your agent can use the inference key at `http://localhost:8080/inf/v1`. See [Use an SDK](/docs/guides/sdks).
  </Step>
</Steps>
