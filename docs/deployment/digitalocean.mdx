---
title: "DigitalOcean"
description: "Run Docker Compose on a Droplet with the checked-in Caddy overlay for automatic HTTPS."
---

Use an Ubuntu Docker Droplet with at least 2 GB of memory. The `deploy/digitalocean/compose.yml` overlay keeps AirLLM's
port private and publishes Caddy on ports 80 and 443.

## Prepare the host

1. Point the domain's DNS record to the Droplet
2. Allow inbound TCP 80 and 443
3. Install Git, Docker with Compose 2.24.4+, Python 3.13+, and uv
4. Clone the repository and copy `.env.example` to `.env`

Set these values in `.env`:

```bash
AIRLLM_DOMAIN=llm.example.com
AIRLLM_PUBLIC_URL=https://llm.example.com
POSTGRES_PASSWORD=replace-with-a-url-safe-random-value
```

Add at least one provider API key for the local `quickstart` command.

## Start and claim

```bash
docker compose \
  -f docker-compose.yml \
  -f deploy/digitalocean/compose.yml \
  up -d --build --wait

uv run --package cli --no-dev --frozen airllm quickstart \
  --url https://llm.example.com
```

Caddy obtains a certificate after DNS and ports 80 and 443 are reachable. Claim the instance immediately after the public route starts responding.

## Update

Back up Postgres and AirLLM state, check out the intended release, and repeat the Compose command. Preserve `.env` and
the named volumes for Postgres, AirLLM, and Caddy certificates. Use the same two `-f` arguments for `logs`, `down`, and
every later Compose operation.
