## Health endpoints

| Endpoint | Healthy response | Failure meaning |
| --- | --- | --- |
| `/healthz` | `200` with queued-event statistics | Process or control-plane proxy is unavailable |
| `/readyz` | `200 {"status":"ready"}` | No bundle or latest manifest was rejected |

The data-plane health payload includes pending outbox events and the age of the oldest queued event. Alert on a growing
queue or oldest age, even while inference remains available.

## CLI diagnostics

```bash
airmux status
airmux doctor
airmux gateways list --all
airmux bundles list
airmux events tail
```

Use `doctor` first to distinguish local profile, control-plane authentication, and gateway readiness failures.

## Backups

Back up these as one recovery point:

1. Postgres
2. Runtime management credential files
3. Provider secret files
4. Each gateway's identity, cached bundles, and SQLite usage outbox

Restrict backup access because the default file secret store contains plaintext provider credentials. Test restoration on isolated infrastructure.

## Updates

The control plane creates its bootstrap credential when absent, migrates Postgres, and applies the shipped taxonomy before
it accepts traffic. A split gateway can keep serving an accepted cached bundle while the control plane is unavailable.
Because pre-1.0 releases do not promise
cross-version compatibility between planes, deploy one image digest across all components. Follow
[Upgrade and rollback](/docs/deployment/upgrades) to restore the database and state together if verification fails.

## Common failures

| Symptom | Check |
| --- | --- |
| `bundle_unavailable` | Bundle poll authentication, control-plane URL, and cached state mount |
| `/readyz` says `bundle rejected` | Gateway logs for an invalid provider, model, credential, or policy reference |
| `credential_backend_unavailable` | Secret-store mount, permissions, and availability |
| Usage missing from console | `/healthz` pending count and control-plane event-ingest reachability |
| New key returns `invalid_token` | Wait for bundle adoption, then inspect `bundles list` and gateway logs |
| Streams pause or buffer | Reverse-proxy buffering and read timeout |
| Control plane refuses startup during migration | Check database reachability and migration errors in its logs |
