# Security Policy

## Reporting a vulnerability

Send security reports privately to [michel.tricot@gmail.com](mailto:michel.tricot@gmail.com). Do not open a public issue or post exploit details in a pull request or discussion.

Include the affected version or commit, the expected impact, and steps to reproduce. Redact credentials and personal data. If evidence cannot be safely redacted, ask for a private way to transfer it before sending it.

When GitHub private vulnerability reporting is enabled for this repository, you may use its **Report a vulnerability** link instead.
